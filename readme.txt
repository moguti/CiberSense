# Reproducibility Material – Experimental Tests

## Overview

This repository contains the code, experimental scripts, and data files used to support the results presented in the associated paper.

The goal is to provide full reproducibility of the experiments and additional material that could not be included in the main manuscript due to space constraints.

## Repository Structure

- **code/**  
  Source code used to run the experiments and generate results
  Source code has been written in Netlogo

- **input data/**  
  Input datasets used in the analysis.

- **results/**  
  Output files, including Excel spreadsheets with and raw experimental data and metrics.

## Experimental Data

The experimental results are provided in Excel format (`.csv`), including:

- Raw measurements
- Processed metrics

These files can be found in the `results/` directory.

Due to the stochastic nature of the model, exact numerical reproducibility of the reported results cannot be guaranteed. However, the experiments consistently reproduce the observed trends, the main statistical properties, and the overall conclusions presented in the paper.

## How to Reproduce Results

1. Clone or download the repository.
2. Install Netlogo: https://www.netlogo.org/
3. Uploap source code in netlogo  
4. Run the source code to observe the main results 
5. Go to BehaviourSpace tool to execute the experiments defined
